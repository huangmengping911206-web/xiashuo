# Xiashuo - 稿件审阅系统

> 基于 AI Agent 的稿件生产与审阅工作流

## 项目结构

```
xiashuo/
├── pipeline/          # Agent 各阶段产出
│   ├── research/      # 资料搜集
│   ├── qa/            # 问答记录
│   └── reviews/       # 审阅意见
├── drafts/            # 稿件版本
└── CHANGELOG.md       # 变更日志
```

## 工作流

1. **搜集** — 根据 Idea 搜集内外网资料
2. **问答** — 对资料进行提问、搜索、分析
3. **写稿** — 整理为口播稿件
4. **审阅** — 多轮审阅，提炼核心，优化叙事
